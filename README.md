# Sahed Mahmud — Academic Portfolio

Personal academic and research portfolio of Sahed Mahmud, Materials Science and Engineering graduate from Khulna University of Engineering & Technology (KUET).

The portfolio highlights research experience, publications, computational and data-driven materials research, academic projects, professional experience, technical skills, certifications, leadership, and related activities.

## Deployment

This website is deployed using GitHub Pages.

Repository:

`sahedmahmud.github.io`

Live website:

`https://sahedmahmud.github.io`

## Main Files

- `index.html` — main portfolio content
- `styles.css` — layout, typography, responsive design, and visual styling
- `script.js` — mobile navigation, scroll animations, dynamic year, and copy-email functionality
- `thanks.html` — confirmation page for CV requests
- `assets/` — images, logo, favicon, and decorative graphics
